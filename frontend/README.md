# WebGIS Parkir Publik Kota Bukittinggi

Aplikasi WebGIS berbasis React, FastAPI, PostgreSQL, dan PostGIS
untuk menampilkan informasi lokasi parkir publik di Kota Bukittinggi.

## Teknologi

### Frontend

- React
- Vite
- Leaflet
- Axios

### Backend

- FastAPI
- SQLAlchemy
- JWT Authentication

### Database

- PostgreSQL
- PostGIS

## Cara Menjalankan Frontend

```bash
npm install
npm run dev
```
